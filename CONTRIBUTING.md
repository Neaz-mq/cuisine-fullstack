# Contributing

This repository is a personal / portfolio project and is not currently
accepting external pull requests or contributions.

It's shared publicly so the code, architecture, and commit history can be
reviewed — not as an open invitation to fork, reuse, or build on it. See
[`LICENSE`](./LICENSE) for the terms.

## Found a bug or have a suggestion?

Feel free to open an issue describing it — that's welcome, and appreciated.
Just note that pull requests implementing a fix won't be merged directly;
any change still goes through the maintainer.

## Questions about this project?

Reach out via [prographr.com](https://prographr.com).
